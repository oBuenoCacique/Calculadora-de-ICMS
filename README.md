# Calculadora de ICMS

Projeto desenvolvido em Python para automatizar o cálculo de ICMS sobre notas fiscais.

## Objetivo

Aplicar conceitos de lógica de programação e Python em uma situação real da área fiscal, permitindo o cálculo automático do valor do imposto a partir do valor da nota fiscal e da alíquota informada.

## Funcionalidades

- Entrada do valor da nota fiscal
- Entrada da alíquota do ICMS
- Cálculo automático do imposto
- Exibição formatada dos resultados

## Tecnologias Utilizadas

- Python 3
